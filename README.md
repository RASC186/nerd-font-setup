# Nerd-Font Installer

This project contains scripts to install and uninstall nerd-fonts in a Debian-based Linux distro.

## Pre-requisites

To use the instalation script, you will need:

1) curl, and
2) unzip.

## Instructions

To install a nerd-font, run 

```
./install
```

To uninstall all nerd-fonts, run

```
./uninstall
```
